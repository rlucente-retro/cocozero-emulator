# CoCo Zero: Waveshare RP2350-PiZero Hardware Emulator

A high-performance hardware emulator for the **Raspberry Pi RP2350B** (Cortex-M33) microcontroller board running the **CoCo Zero** bare-metal firmware ([ugufru/xroar-waveshare-rp2350-pizero](https://github.com/ugufru/xroar-waveshare-rp2350-pizero)).

The emulator runs the authentic CoCo Zero firmware binary, accurately simulating the underlying RP2350B silicon to deliver a standalone **Tandy Color Computer 2 (CoCo 2)** / Dragon 32 virtual machine complete with video scanout, digital audio, virtual FAT32 MicroSD storage, and full keyboard matrix input.

---

## Features

- **Dual-Core ARM Cortex-M33 Emulation:** Simulates both CPU cores running at a nominal 252 MHz system clock, including hardware TMDS encoding, SIO interpolator, and inter-core FIFO communication.
- **Hardware-Accelerated Framebuffer Extraction:** Extracts 320×240 RGB565 frames directly from RP2350 SRAM and upscales to 640×480 @ 60 Hz via SDL2.
- **Digital Audio:** Captures 48 kHz 16-bit stereo PCM audio streams generated by the 6809 DAC and SN76489 sound chip.
- **MicroSD Card (SPI1) & Virtual FAT32 Engine:** Auto-packages host directories (such as `./coco`) into virtual FAT32 block devices on the fly, eliminating the need to manually build raw disk images.
- **Zero-Latency Keyboard Matrix Injection:** Translates host PC and USB keyboard inputs directly into the firmware's in-RAM MC6821 PIA0 $8 \times 8$ matrix (`0x2000_b1ac`), supporting real-time typing, symbol chords, and multi-key game controls.
- **Virtual Clock Turbo Scaling:** Supports `--turbo <N>` virtual clock scaling (e.g. `--turbo 6`) to achieve real-time 60 FPS performance on standard workstations.

## Prerequisites & Installation

### 1. Install Rust Toolchain

The project is built in modern Rust. If you do not have Rust installed, install it using `rustup`:

#### macOS / Linux
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
Follow the on-screen prompts, then restart your terminal or run:
```bash
source "$HOME/.cargo/env"
```

Verify the installation:
```bash
rustc --version
cargo --version
```

### 2. Install SDL2 Dependencies

The emulator frontend uses **SDL2** for video, audio, and keyboard input.

#### macOS (via Homebrew)
```bash
brew install sdl2 pkg-config
```

#### Ubuntu / Debian
```bash
sudo apt-get update
sudo apt-get install -y libsdl2-dev pkg-config build-essential
```

#### Fedora / RHEL
```bash
sudo dnf install -y SDL2-devel pkgconfig
```

#### Windows
Install SDL2 development libraries via [vcpkg](https://vcpkg.io/) or download the MSVC development package from [libsdl.org](https://github.com/libsdl-org/SDL/releases).

## Building the Project

Clone the repository and build using Cargo:

```bash
# Build optimized release binary
cargo build --release

# Run the complete automated test suite
cargo test --tests --release
```

The compiled binary will be located at `target/release/cocozero-rp2350`.

## Running the Emulator

### Quick Start (Recommended)

To launch the emulator with full interactive display, audio, and **real-time 60 FPS performance**:

```bash
cargo run --release -- --turbo 6
```

> **Note:** By default, running without additional arguments will automatically load:
> - Firmware: `roms/cocozero.uf2`
> - Boot ROM: `roms/rp2350/bootrom-combined.bin`
> - MicroSD card: The host `./coco` directory packaged as a virtual FAT32 card containing the required Color BASIC ROMs (`bas12.rom`, `extbas11.rom`, `disk11.rom`).

---

## Command-Line Options

```text
Usage: cocozero-rp2350 [OPTIONS]
```

| Option | Flag | Description | Default |
|---|---|---|---|
| `--turbo <N>` | | **Virtual clock scaling factor.** Multiplies the virtual cycle speedup.<br>• `--turbo 1`: 10.5 FPS (cycle-exact 252 MHz step)<br>• `--turbo 4`: ~38 FPS<br>• `--turbo 6`: **~60 FPS (smooth real-time)** | `1` |
| `-u, --uf2 <PATH>` | `-u` | Path to firmware UF2 binary (`.uf2`). | `roms/cocozero.uf2` |
| `-b, --bin <PATH>` | `-b` | Path to raw flash firmware binary (`.bin`). | *None* |
| `--bootrom <PATH>` | | Path to RP2350 Boot ROM binary. | `roms/rp2350/bootrom-combined.bin` |
| `-s, --sd <PATH>` | `-s` | Path to a raw SD card `.img` file **or** host directory to dynamically package into virtual FAT32. | `./coco` |
| `--headless` | | Runs headlessly without opening an SDL2 window (ideal for CLI benchmarking and scripted tests). | `false` |
| `--max-frames <N>` | | Automatically exit after $N$ frames (`0` = run indefinitely). | `0` |
| `--fb-addr <ADDR>` | | Override the internal SRAM framebuffer base address (e.g. `--fb-addr 0x20022744`). | `0x20022744` |
| `-h, --help` | `-h` | Display help information. | |
| `-V, --version` | `-V` | Display version information. | |

## Common Usage Examples

### 1. Interactive Emulation at 60 FPS
Opens the 640×480 SDL2 window with audio and keyboard enabled:
```bash
cargo run --release -- --turbo 6
```

### 2. Mount a Custom Host Directory as the MicroSD Card
```bash
cargo run --release -- --turbo 6 --sd /path/to/my_coco_folder
```

### 3. Mount a Pre-Built Raw MicroSD Image File (`.img`)
```bash
cargo run --release -- --turbo 6 --sd /path/to/sdcard.img
```

### 4. Run Headless Benchmark / Smoke Test
Run for 180 frames (approx. 3 simulated seconds) without opening a window:
```bash
cargo run --release -- --headless --max-frames 180 --turbo 6
```

### 5. Flash an Alternate Firmware Binary
```bash
cargo run --release -- --turbo 6 --uf2 path/to/custom_firmware.uf2
```

## MicroSD Card Directory Layout

When pointing `--sd` to a directory (or using the default `./coco/` directory), the structure should follow standard CoCo Zero conventions:

```text
coco/
├── roms/
│   ├── bas12.rom       # Color BASIC 1.2 ROM (8192 bytes, required)
│   ├── extbas11.rom    # Extended Color BASIC 1.1 ROM (8192 bytes, optional)
│   └── disk11.rom      # Disk BASIC 1.1 ROM (8192 bytes, optional)
├── dsk/                # Floppy disk images (.dsk)
├── bin/                # Executable binary files (.bin)
├── cart/               # Cartridge ROM images (.ccc)
├── shots/              # Screenshots destination
├── settings.txt        # System configuration settings
└── autorun.txt         # Auto-execution boot script
```

## Keyboard Controls & Matrix Mapping

All keystrokes typed into the emulator window are translated into the physical $8 \times 8$ matrix read by the 6809 CPU via MC6821 PIA0:

| Host / PC Key | Tandy Color Computer 2 Function | Description / Notes |
|---|---|---|
| **`A` – `Z`** | Letters `A` – `Z` | Normal case in Color BASIC |
| **`0` – `9`** | Digits `0` – `9` | Numeric keypad also mapped |
| **`Enter` / `Return`** | `ENTER` | Executes BASIC commands |
| **`Backspace` / `Delete`** | `LEFT` ($\leftarrow$) | Erases previous character |
| **`Escape`** | `BREAK` | Interrupts and stops running programs |
| **`Spacebar`** | `SPACE` | Space character / Primary game fire button |
| **`Arrow Keys`** ($\uparrow, \downarrow, \leftarrow, \rightarrow$) | `UP`, `DOWN`, `LEFT`, `RIGHT` | Navigation & movement in games |
| **`Shift`** | `SHIFT` | Shift modifier |
| **`Home`** | `CLEAR` | Clears screen in BASIC |
| **Symbols (`"`, `!`, `?`, `*`, `+`, `=`, etc.)** | Automatic CoCo Chords | Automatically pulses chords (e.g. `"` pulses `Shift + 2`) |

### CoCo Zero Special Function Keys

- **`F1`**: Toggle On-Screen Diagnostics & Info Overlay
- **`F8`**: Cycle PMODE 4 NTSC Artifact Color Phase (*on / swapped / off*)
- **`F9`**: Programs Menu
- **`F10`**: Cartridges Menu
- **`F12`**: Floppy Disk Image Mount Overlay
